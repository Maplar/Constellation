# 当前文件中心与自由命名专题设计

## 目标

把 Constellation v4 前端 UI 校准台从“学科研究空间”改为通用知识库界面。软件既服务研究者，也服务自学者、高中生、媒体工作者和日常记录者；体系化研究是可选能力，不是默认用户身份。

本轮只修改静态前端 UI 校准台与规范文档，不实施真实前后端。

## 当前文件中心

- 完全删除编辑区顶部 Tab 栏。
- 文件树当前选中的文件是唯一上下文。
- 左侧应用图标栏是编辑器、图谱、知识树、JSON Canvas、仪表盘和 AI 的唯一常驻导航。
- 图谱、知识树和 JSON Canvas 视图标题必须明确显示它们正在围绕哪个当前文件工作。
- `.mindmap.md` 和 `.canvas` 仍是文件树中的正式真实文件，不改变文件事实源或业务模型。

## 主编辑区层级

- 当前专题是文档上下文，使用小号眉题显示，不参与 Markdown 标题层级。
- 顶部文件标题是当前文档唯一 H1，也是主编辑区唯一视觉主标题。
- 正文编辑区明确标记为“正文 · 从二级标题开始”，默认只提供正文、H2 和 H3。
- 标题菜单中的 H1 只作为“文档标题 · 顶部唯一”的只读说明，不得在正文内重复插入。
- Markdown 源码中的首个 H1 与顶部文件标题表示同一事实，不得在可视正文中重复渲染第二个大标题。

## 通用知识库

- 顶部只显示 Constellation 与当前功能名称，不显示“数学研究”等空间选择器。
- 文件栏标题固定为“我的知识库”，副标题表达本地工作区和文件数量。
- 文件树可以同时包含学习、写作、生活、项目等普通文件夹，不要求用户先建立知识体系。

## 自由命名专题

- 原“研究空间”改为可选的“专题”功能，并下移到文件栏。
- “专题”是通用功能名称；每个专题的实际名称由用户自由填写，例如“数学体系”“期末复习”“视频选题”或任何自定义名称。
- 专题只保存一组聚焦范围、局部索引和关联视图配置，不创造第二份正文，不替代真实文件夹。
- 用户可从“新建 -> 专题”输入名称创建；静态原型只添加可点击的专题项，不写入真实工作区。
- 用户不创建专题时仍可使用全部笔记、文件树、编辑器和其他核心能力。
- 专题面板默认折叠，折叠后保留当前专题颜色、名称和专题数量。
- 展开后显示全部专题；切换或新建专题时，折叠摘要必须同步更新。

## 右侧关系栏

- 右侧只显示当前文件的显式引用和反向链接等只读关系信息。
- 删除右栏中的局部图谱预览和建立引用流程，因为图谱由左侧图标进入，引用由编辑器工具栏建立。
- 右栏默认折叠，正文自动占满释放宽度。
- 右栏折叠时正文采用居中的自适应阅读版心并适度加宽；展开后缩窄但仍保持居中，右侧不得出现疑似预留功能区的大块空白。
- 只保留一个贴近右边缘的展开箭头；展开后箭头用于再次折叠，不形成第二条图标侧栏。

## 暗色文件树

- 文件夹与文件节点必须清除原生按钮外观，普通状态使用透明主题表面。
- 悬停、选中、目录展开和快捷便签区域统一使用 Design Tokens。
- 后续校准已删除“全库入口”、收件箱和全局附件栏目；快捷便签作为最后一个真实文件之后的独立折叠区显示。
- “同步与留痕”作为按需状态区默认折叠，展开后才显示同步工具与 Git 留痕详情。
- 快捷便签允许多个未整理草稿并标出唯一活动草稿；用户确认整理后移动到目标真实文件夹。
- Light、Dark、Warm 三套主题不得出现浏览器默认白色按钮底色。

## 验收标准

1. 顶部不存在研究空间选择器或固定学科身份。
2. 编辑区不存在 Tab 栏。
3. 文件栏标题为“我的知识库”，并显示可选专题区。
4. 新建专题时名称完全由用户输入。
5. 左侧图标栏是视图导航的唯一常驻入口。
6. 图谱、知识树和 Canvas 明确对应当前文件。
7. 右侧关系栏默认折叠，展开后只显示引用与反向链接。
8. 暗色主题下文件树无白色原生按钮背景。
9. 顶部文件标题是唯一 H1，正文标题从 H2 开始。
10. 专题默认可折叠，折叠摘要显示当前专题和数量。
11. README 和 AGENTS 不再把“研究空间”定义为主窗口架构。
