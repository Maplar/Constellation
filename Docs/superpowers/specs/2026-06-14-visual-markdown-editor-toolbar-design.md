# 可视化 Markdown 编辑器工具栏设计

## 目标

Constellation 的普通 Markdown 编辑默认使用所见即所得的可视化编辑区。用户直接编辑渲染后的标题、段落、列表、引用和引用胶囊，不在默认界面中直接暴露 Markdown 源码。

## 默认界面

- 当前预览正文改为可编辑正文，并成为默认编辑区。
- 顶部不再展示“编辑 / 分栏 / 预览”三段切换。
- 命令栏显示“可视编辑”状态；Markdown 源码进入右上角“…”高级菜单。
- 源码模式用于检查和高级修改，不与可视化正文长期并排，避免普通编辑时分散注意力。
- 正文聚焦时只显示文字插入光标，不显示贯穿正文高度的侧边焦点线。
- 正文和关系面板使用透明轨道、细圆角中性色滑块，不显示系统白色滚动条。
- 标题层级采用自绘圆角菜单，菜单背景、边框、悬停和选中态全部继承 Design Tokens。

## 精简 Word 风格工具栏

工具栏位于文档标题与正文之间，按高频任务分组：

1. 撤销、重做。
2. 段落样式：正文、一级标题、二级标题、三级标题。
3. 文本：粗体、斜体、删除线、行内代码。
4. 段落：左对齐、居中、右对齐。
5. 结构：无序列表、有序列表、引用、分割线。
6. 插入：链接、引用胶囊、图片、附件。

低频的字体、字号、文字颜色、行距和复杂段落参数不进入默认工具栏，继续放入设置或后续高级菜单。

## 交互与数据边界

- 静态 UI 校准台用 `contenteditable` 演示直接编辑与按钮反馈。
- 正式实现必须由结构化 Markdown 编辑器模型和 Markdown AST 完成双向转换，禁止依赖 `innerHTML` 或脆弱字符串替换作为事实源写入方式。
- 可视化编辑仍保存标准 Markdown；引用胶囊、内容嵌入和来源框只是编辑视图。
- 源码模式与可视化模式操作同一文档 revision，不得维护两份正文状态。

## 状态

- 正文发生编辑或格式操作后显示“未保存”。
- 保存仍走后续 `DocumentService` 原子写入和 revision 冲突检测。
- 静态校准中的图片、附件和链接按钮只表达入口与状态，不接入系统文件弹窗或真实后端。
