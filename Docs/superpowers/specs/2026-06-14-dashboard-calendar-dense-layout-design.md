# 仪表盘日历与紧凑布局设计

## 已确认目标

- 自由仪表盘新增“编辑活动日历”核心卡片。
- 仪表盘区域尽量铺满，减少卡片之间因跨列和跨行尺寸组合产生的空洞。
- 本轮只更新计划和前端 UI 校准台，不接入真实 Git 或文件保存事件。

## 日历卡片

- 使用月历热力图，不采用全年贡献格。
- 日期格用颜色深浅表达当日修改次数。
- 每个有活动的日期显示修改次数和涉及文件数。
- 点击日期后，在卡片右侧显示当天摘要，包括保存次数、文件数和最近修改文件。
- 未来数据采用混合来源：Git 提交作为可靠历史，本地保存事件补充当天修改频率。

## 紧凑铺满规则

- 仪表盘继续使用 12 列网格和卡片尺寸层级。
- 启用 dense 自动补位，让后续小卡片填补前面产生的空格。
- 日历卡片使用 8 × 3，AI 建议卡片使用 4 × 3，组成完整 12 列大行。
- 其余 4 × 2 卡片按三个一组铺满整行；四张 3 × 1 统计卡铺满首行。
- 保留小间距以维持卡片边界，不追求无间距拼贴。
