# 编辑标注与对象自适应右键菜单设计

## 范围

本设计只用于 Constellation v4 前端 UI 校准台和后续正式前端规划，不实施真实 Markdown AST、文件系统、图谱、知识树或 JSON Canvas 写入。

目标：

- 让用户在选中文字后直接添加 Markdown 块引用、普通下划线或文字感悟。
- 让不同页面、不同对象拥有精确且精简的右键菜单。
- 避免把所有功能塞入同一通用菜单，也避免大量不可执行的灰色菜单项。
- 保持 Light、Dark、Warm 三套主题下统一的菜单结构、密度和 Design Tokens。

## 文字选区工具条

### 出现条件

- 只有编辑器正文存在有效非空文字选区时才显示。
- 工具条靠近选区上方，并避开当前选中文字。
- 单击编辑区空白、改变选区或按 `Esc` 后关闭。
- 触屏设备后续可通过长按选区调用同一动作集合，本阶段只校准桌面端。

### 动作

工具条只包含三个主要动作：

```text
❝ 块引用    U 下划线    感 感悟
```

顶部编辑工具栏继续保留这三个入口，正文选区右键菜单也可提供同样动作，但选区浮动工具条是最短操作路径。

### Markdown 块引用

- 块引用作用于选区涉及的完整段落，不只包裹选中的几个字。
- 多段选区转换为连续的 Markdown 引用段落。
- 已位于块引用中的完整段落再次执行时退出块引用。
- 底层保存为标准 Markdown `>`，不引入私有语法。
- 块引用用于摘录、原话或需要保留来源语气的内容，不承担“文字感悟”功能。

示例：

```markdown
> 真正可靠的知识系统，应当让碎片能够被保存、被找到。
```

### 普通下划线

- 下划线只作用于精确文字选区。
- 已全部处于下划线状态的选区再次执行时取消下划线。
- 只提供单一下划线，不增加荧光笔、双下划线、波浪线或颜色选择。
- 底层使用可读的内联 HTML `<u>文字</u>`，不引入私有 Markdown 语法。

示例：

```markdown
集合描述的是<u>成员关系</u>。
```

### 文字感悟

- 用户选中文字后点击“感”，在选区末尾生成顺序编号上标，例如 `感₁`。
- 点击上标后，在锚点附近显示宽度约 `360–480px` 的横向悬浮卡片。
- 卡片显示原文摘要、可编辑感悟、保存和删除操作。
- 悬停只高亮锚点，点击才打开卡片。
- 感悟不改变原段落层级，也不得嵌套成 Markdown 块引用。
- 正式实现优先使用 Markdown 脚注保存感悟，并由结构化编辑器和 Markdown AST 维护锚点、编号与删除。

示例：

```markdown
集合描述的是成员关系[^insight-1]。

[^insight-1]: 学习抽象概念时，应先理解它解决的组织问题。
```

可视化编辑器把 `[^insight-1]` 渲染为 `感₁`，默认正文不直接暴露脚注源码。

## 右键菜单生成原则

### 页面与对象共同决定菜单

菜单由“当前页面 + 命中对象 + 当前状态”共同生成。例如：

- 图谱页面空白区域和图谱节点拥有不同菜单。
- Canvas 文件节点和 Canvas 边拥有不同菜单。
- 编辑器文字选区和普通段落拥有不同菜单。

不适用的动作直接不显示，不使用长菜单加大量灰色禁用项。

### 空白区域

页面空白区域只显示 `2–4` 个页面级动作。例如：

- Canvas 空白：新建文本、粘贴、适应视图。
- 图谱空白：适应视图、重置布局、筛选关系。
- 仪表盘空白：添加卡片、自动补位、恢复默认布局。

### 菜单层级

- 首层最多显示 `6` 个主要动作。
- 超出部分进入“更多”二级菜单。
- 常用动作在顶部，导航和编辑动作居中，危险操作固定在底部。
- 删除、移除引用等动作使用柔和警示色，不使用大面积红色。
- 真实文件删除必须进入回收站或提供撤销，不得立即永久删除。

## 页面与对象菜单矩阵

### 编辑器

| 对象 | 首层动作 |
|---|---|
| 文字选区 | 复制、块引用、下划线、写感悟、链接/引用 |
| 普通段落 | 粘贴、在下方插入、切换段落类型 |
| 编辑区空白 | 粘贴、插入段落 |
| 引用胶囊 | 打开来源、展开/收起预览、在图谱查看、移除引用 |
| 感悟上标 | 打开感悟、编辑、删除 |

编辑器选区菜单不得重复字体、颜色、行距等低频排版功能；这些能力继续放在设置或高级菜单。

### 文件树

| 对象 | 首层动作 |
|---|---|
| Markdown 文件 | 打开、重命名、移动、复制相对路径、移入回收站 |
| `.mindmap.md` 文件 | 打开知识树、重命名、移动、复制相对路径、移入回收站 |
| `.canvas` 文件 | 打开 Canvas、重命名、移动、复制相对路径、移入回收站 |
| 文件夹 | 新建笔记、新建知识树、新建 Canvas、重命名、移动 |
| 文件树空白 | 新建文件、新建文件夹、折叠全部 |
| 快捷便签 | 续写、重命名、整理到文件夹、转磁贴、移入回收站 |

### 知识图谱

| 对象 | 首层动作 |
|---|---|
| 文件节点 | 打开文件、聚焦节点、展开一跳、在文件树定位、隐藏节点 |
| 来源节点 | 打开来源、查看证据、聚焦节点、隐藏节点 |
| 显式关系边 | 查看关系来源、跳转引用位置、临时隐藏 |
| 图谱空白 | 适应视图、重置布局、筛选关系 |

图谱右键菜单只负责浏览、筛选和跳转，不允许直接创建知识树结构或把图谱边写入正文。

### 知识树

| 对象 | 首层动作 |
|---|---|
| 结构节点 | 新建子节点、重命名、提升/降级、转为笔记、聚焦分支 |
| 知识笔记节点 | 打开笔记、新建子节点、改变父级、聚焦分支、从树中移除 |
| 子树入口 | 打开子树、聚焦、改变父级、从树中移除 |
| 知识树空白 | 新建根级节点、全部展开、适应视图 |

“从树中移除”只修改 `.mindmap.md` 结构，不删除被链接的真实文件。

### JSON Canvas

| 对象 | 首层动作 |
|---|---|
| 文本节点 | 编辑、复制、连接、分组、删除 |
| 文件节点 | 打开文件、复制、连接、分组、删除 |
| 链接节点 | 打开链接、复制、连接、分组、删除 |
| 分组 | 重命名、自动包围所选节点、取消分组、删除 |
| 边 | 编辑端点、改变方向、删除 |
| Canvas 空白 | 新建文本、粘贴、适应视图 |

菜单动作必须保持 JSON Canvas 1.0 标准数据边界，不加入知识树专用父子操作。

### 自由仪表盘

| 对象 | 首层动作 |
|---|---|
| 仪表盘卡片 | 刷新、调整尺寸、复制卡片、移除 |
| 仪表盘空白 | 添加卡片、自动补位、恢复默认布局 |

移除卡片只修改仪表盘布局，不删除真实笔记。

### AI 与来源

| 对象 | 首层动作 |
|---|---|
| AI 检索结果 | 打开来源、引用到正文、保存证据、在图谱查看 |
| URL 来源 | 打开来源、查看证据、引用到正文、在图谱查看 |
| AI 建议 | 查看差异、应用建议、忽略建议 |
| 页面空白 | 新建检索、清空当前结果 |

AI 建议必须保持确认后写入；右键菜单不得绕过差异预览直接修改正文。

### 设置与组件校准

- 设置页面默认使用标准表单交互，不提供全页面自定义右键菜单。
- 组件校准页可右键具体示例组件，显示“复制状态、查看 Token、重置示例”等校准动作。
- 不为仅展示说明文字的区域创建无意义菜单。

## 视觉规范

- 菜单顶部显示小号对象类型，例如“正文选区”“图谱节点”“Canvas 文件节点”。
- 菜单宽度约 `180–220px`，根据最长动作文字微调，但同类菜单保持一致。
- 使用项目圆角、边框、阴影、字体和 Design Tokens，不依赖系统原生菜单。
- 图标用于快速识别，文字负责明确含义；禁止只有图标没有文字。
- 分组之间使用细分隔线，不为每个动作增加独立卡片框。
- 菜单位置自动避开当前选区、节点和屏幕边缘。
- 支持方向键上下选择、`Enter` 执行、`Esc` 关闭。
- Light、Dark、Warm 保持相同层级、尺寸和动作顺序，只改变主题 Token。

## 校准台交互范围

前端 UI 校准台需要表达：

1. 编辑器选中文字后出现三动作浮动工具条。
2. 块引用、下划线和感悟分别产生可见效果。
3. 至少展示编辑器、文件树、图谱、知识树、Canvas、仪表盘和 AI 来源的对象菜单。
4. 在不同页面或对象上右键时，单一菜单容器动态替换标题和动作。
5. 页面空白菜单保持 `2–4` 个动作。
6. 危险动作位于末尾，并以柔和警示色表达。
7. 设置页面不强行展示自定义菜单。

校准台只模拟动作和状态变化，不写入真实文件、引用、知识树或 Canvas。

## 验收标准

- 有效文字选区出现 `块引用 / 下划线 / 感悟` 浮动工具条。
- 三种标注的视觉和 Markdown 语义彼此独立。
- 右键菜单随页面和命中对象变化。
- 任一首层菜单不超过 `6` 个主要动作。
- 空白区域菜单不超过 `4` 个动作。
- 不显示不适用的灰色菜单项。
- 文件删除、树节点移除和仪表盘卡片移除的语义明确区分。
- Light、Dark、Warm 下菜单可读且不暴露系统原生样式。
- 不重新引入 Tab、私有 Markdown 语法、图谱编辑或知识树/Canvas 模型重叠。
