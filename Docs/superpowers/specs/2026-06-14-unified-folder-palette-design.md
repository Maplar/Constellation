# 统一文件夹调色盘设计

## 已确认目标

在前端 UI 校准台的“独立表面”中增加统一调色盘。调色盘当前操作对象是所选文件夹，例如 `01 研究 / 哲学`。

## 颜色规则

- 文件夹颜色是唯一事实源，未来持久化位置为 `.constellation/folders.json`。
- 调色盘修改源文件夹颜色，不为引用、知识树或图谱创建独立颜色覆盖。
- 引用胶囊与内容框、知识树节点、图谱节点按其目标文件所在文件夹同步继承颜色。
- 失效链接、错误、警告和学习状态仍使用各自语义状态色，不被文件夹颜色覆盖。

## 校准台交互

- “独立表面”新增“统一调色盘”入口。
- 浮层显示当前对象、专业色相环、中央饱和度/明度区和同步规则说明。
- 默认操作层只保留原始色/UI 安全色双预览、HEX 输入、六个既有彩虹预设、最近颜色、吸管占位、恢复默认、取消和应用。
- UI 安全色保留原始色相，并把过高饱和度、过亮或过暗的颜色收敛到适合界面的柔和范围；用户可以明确选择应用原始色或 UI 安全色。
- RGB、HSL、明度、饱和度、透明度、安全色生成强度、对比度检查和最近颜色管理移入“设置 -> 外观与编辑 -> 高级取色”。
- 浮层同时展示文件夹、引用、知识树、图谱四类预览。
- 调整色环、饱和度/明度区、HEX 或预设色后，四类预览立即使用草稿颜色；“取消”恢复已应用颜色，“应用”才确认源文件夹颜色。
- 本轮只实现静态视觉与交互校准，不接入真实文件写入或后端服务。
