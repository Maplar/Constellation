# 来源集合颜色 UI 校准实施计划

> **For Codex:** 使用 `executing-plans` 的检查点思路逐项实施；本轮只修改静态前端 UI 校准台，不接入真实前后端。

**目标：** 让本地文件、URL 与 AI 来源分别继承其文件夹或来源集合颜色，并在引用胶囊、连接线、内容框、知识图谱和统一调色盘中保持一致。

**架构：** 静态校准页使用 `data-color-target` 表达颜色事实源作用域。调色盘只预览和提交当前目标，来源类型图案继续负责类型识别，颜色负责集合识别；AI 来源引用与 AI 相似关系使用不同节点和边样式。

**技术栈：** 单文件 HTML、CSS Variables、原生 JavaScript、Playwright 视觉检查。
