## 源码保留规则

已完成但尚未与 1.0 数据契约兼容的 Constellation 实验模块，会保存在 `src/modules/_archived/2.0/`。该目录被 1.0 的 TypeScript 配置排除：它保留实现资产和历史上下文，但不会成为 1.0 的运行时入口或编译依赖。恢复某项前，必须先按当时的 Core contract 重新接入并补齐测试。
