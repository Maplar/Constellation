笛卡尔与方法论

怀疑并不是摧毁知识，而是寻找不可继续怀疑的起点。

第 18–22 行 · keyword + semantic + link
沉思录摘记

“我思故我在”首先确认的是思考活动本身的不可否认性。

第 8–13 行 · keyword + title
理性主义与经验主义

理性主义强调某些知识可以不依赖感觉经验而成立。

第 26–31 行 · semantic + link
笛卡尔为什么把怀疑作为方法？它和知识可靠性有什么关系？
笛卡尔的怀疑是一种筛选工具，而不是永久立场。他先暂时搁置可能出错的判断，再寻找无法通过怀疑推翻的起点 。 在当前知识库材料中，这个起点被概括为“思考活动本身不可否认”，随后再以清楚分明的观念重建知识 。

因此，怀疑与知识可靠性的关系是：先暴露证据链中的薄弱部分，再把可说明来源、推理路径和适用范围的判断保留下来 。
